# Krunker-botter
A tool that sends bots to krunker.io games


How to use it

Download the .zip from the repo and unzip

make a file called accounts.txt in user:pass format one per line (optional skipping it will only allow you to send guests)
make a file called proxies.txt in http://user:pass@ip@port format one per line 

run KrunkerBotter.exe and follow the CLI setup
